# EOS — Engineering Performance Analyzer

EOS is a Windows desktop application for consolidating engineering performance data from ERP exports, employee master data, attendance records, timesheets, and structured peer-review workbooks.

The application is designed for local, auditable analysis. Imported files, calculated monthly metrics, employee classifications, review data, and generated reports are stored on the workstation in SQLite. No cloud service is required for normal operation.

## Purpose

EOS brings together operational data that is normally spread across several reports and workbooks, then presents it through a single monthly analysis workspace.

It supports:

- monthly engineering performance analysis
- timesheet completion and approval monitoring
- attendance, leave, UAA, punch, and duration reconciliation
- workload and utilization analysis
- employee and team administration
- peer-review collection and analysis
- employee-level drill-downs
- formatted Excel reporting
- import history and source validation

## Current application

- .NET 10 Windows desktop host
- WPF shell with Blazor Hybrid UI
- SQLite persistence through Entity Framework Core
- ClosedXML-based Excel import and export
- Apache ECharts bundled locally for offline analytics
- self-contained Windows x64 deployment
- automated domain, database, and workbook tests

## Main workflow

1. Select the reporting month.
2. Import the three ERP exports.
3. Review validation status and imported rows.
4. Generate personalized review workbooks.
5. Collect and import completed reviews.
6. Review team and employee analytics.
7. Export team or individual reports.

## Data inputs

EOS detects workbook types from their column structure rather than relying only on file names.

| Input | Expected source | Purpose |
| --- | --- | --- |
| Monthly utilization summary | RP-wise Timesheet Utilization Report | Capacity, entered hours, approvals, billable and non-billable effort |
| Detailed timesheet | Timesheet Manager/Head Report | Daily project, activity, task, approval, and effort records |
| Attendance and leave | Leave Summary for RP | Punches, attendance, leave, UAA, late coming, early going, and duration flags |
| Engineer reviews | Workbooks generated by EOS | Self-review and peer-review ratings and comments |
| Employee roster | ERP employee master export | Employee identity, level, email, employment classifications, and roster-driven flags |

### Reporting-period handling

Attendance and detailed-timesheet exports carry dates on individual rows. A single file may therefore contain several months, and EOS assigns each row to its actual reporting month.

The utilization summary is different: each row contains one aggregate total for the exported date range. A summary spanning multiple calendar months is rejected because the workbook does not contain enough information to split those totals accurately. Generate one utilization export per calendar month.

## Application areas

### Overview

The Overview page provides the primary monthly management view:

- KPI summary
- score distribution
- workload and utilization analysis
- category-performance visualizations
- top-quartile and attention lists
- peer-review network and participation metrics
- attendance-versus-timesheet reconciliation
- exception summaries
- employee performance table
- interactive employee profile drill-downs

Historical trend and comparison views become available as additional months are imported.

### Timesheets

The Timesheets workspace focuses on operational completion and approval:

- expected versus filled days
- entered and approved hours
- billable and non-billable effort
- attendance and punch comparisons
- approval status
- missing or incomplete records
- employee-level filtering and sorting

### Peer Insights

Peer Insights presents the complete monthly review network:

- ratings received and given
- collaboration, communication, reliability, and technical-help dimensions
- reviewer participation
- written comments
- network relationships between reviewers and subjects

Blank review rows are not counted as feedback.

### Data imports

The import workspace provides:

- source-slot validation
- expected export guidance
- individual workbook upload
- ZIP package import
- file replacement
- reporting-month context
- import timestamps
- import history
- readiness checks

Re-importing a source replaces the current data for the same source and reporting month while retaining an audit record of the import activity.

### Imported data

The Imported Data workspace exposes the normalized rows produced by each source, together with upload history. It is intended for validation, investigation, and reconciliation rather than primary analysis.

### Employees & teams

The employee master supports:

- ERP roster import
- employee code and identity
- seniority level
- team assignment
- billable and non-billable classification
- consultant status
- probation status with optional manual override
- roster-driven Up-down status with optional manual override
- inclusion in or exclusion from analysis
- employee analysis drill-down
- team creation, renaming, and removal

Employee names imported from the ERP roster remain read-only in the grid because imported data is matched against those identities.

### Review templates

EOS generates personalized Excel review workbooks for one engineer or the complete team. Generated workbooks contain the applicable review structure and metadata required for reliable re-import.

### Reports

The Reports workspace exports formatted Excel reports for:

- the full engineering team
- an individual engineer

Reports use the same calculated data shown in the application and include structured tables, score bands, print settings, and review information where available.

### Scoring

Operational scores are currently calculated from available system data using:

- timesheet completion: 55%
- approval completion: 15%
- attendance discipline: 30%

A component is included only when its source data is available. Missing source data is not treated as a zero score.

The Scoring page also presents the proposed seven-category review-weight model:

- assignment execution
- ownership and accountability
- collaboration
- operational discipline
- professional excellence
- continuous improvement
- growth and learning

At present, this page is a configuration and contribution preview. Its values are not yet persisted or versioned by reporting month.

## Data and identity handling

Employee names are normalized before matching because ERP exports may contain inconsistent spacing or capitalization.

Employee classifications may come from the roster, from a manual override, or from local application configuration depending on the field. Analysis inclusion is managed as application data and is not documented as a hard-coded list of individuals.

## Local storage

Application data is stored under:

```text
%LOCALAPPDATA%\EngineeringPerformance
```

This location contains the SQLite database and local application working data. Back up this folder before manual database maintenance or migration work.

## Run from source

Requirements:

- Windows 10 or Windows 11
- .NET 10 SDK
- Visual Studio 2026 or another environment capable of building WPF and Blazor Hybrid projects

```powershell
dotnet restore
dotnet run --project src/EngineeringPerformance.DesktopHost
```

## Build and test

```powershell
dotnet build EngineeringPerformance.slnx -c Release
dotnet test EngineeringPerformance.slnx -c Release --no-build
```

## Publish

```powershell
dotnet publish src/EngineeringPerformance.DesktopHost/EngineeringPerformance.DesktopHost.csproj `
    -c Release `
    -r win-x64 `
    --self-contained true
```

The desktop host targets `net10.0-windows10.0.19041.0` and publishes as a self-contained Windows x64 application.
